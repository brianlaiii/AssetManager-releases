# Asset Manager

A Maya tool for browsing, publishing, and reusing versioned assets.

## Downloads

Use the installation packages attached to this repository's GitHub Releases.
The automatic Source code archives contain this release page, not the Maya installation package.

The first release is being prepared. Installation and compatibility details will be added with it.

## Updates

Public packages will include a Check for Updates button in Settings.
Updates will be downloaded from this repository's published releases.
A new version will take effect after restarting Maya.
